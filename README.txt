FC-MAXIM MUKHTAR — Website + installable PWA starter

Files:
- index.html: responsive bilingual website
- visiting-card.jpg: your supplied visiting card image
- manifest.json and sw.js: basic install/offline support

Preview locally:
1. Extract this ZIP.
2. Open index.html in a browser. The WhatsApp and call buttons are active.
3. For PWA install/offline support, host the folder on an HTTPS website (service workers do not work from file://).

WhatsApp:
The link uses the international format for 0303-6707598: https://wa.me/923036707598
The destination opens only if the number is registered with WhatsApp.

Publishing:
This package is a ready-to-host starter, not yet published to a public domain or app store. To make it live, upload the folder to a static host. A native Android/iOS store app would require a separate app build and publishing steps.
